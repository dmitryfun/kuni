# kuniman.me

Личная страница Kuni Man: живая фотографическая модель, крупное имя, спокойное движение и маленькая кнопка паузы. Next.js 16, React 19, Three.js. Шрифты и изображения находятся в проекте. Страница предназначена для размещения на собственном сервере через Caddy.

Портрет — настоящий фоториг glTF с отдельными костями корпуса, головы, языка, обеих рук и десяти пальцев. Поза: кисть на груди, жест V у рта. Движение задаётся экспортированным циклом `Kuni_Idle`, а не набором ползунков на сайте. Небольшой шарик сохранён отдельным объектом.

## Запуск

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Проверка и сборка:

```sh
pnpm typecheck
pnpm build
```

Шрифты Manrope и Geist Mono сохранены локально из ранее собранного исходного проекта. Сборке не требуется скачивать шрифты. Их исходники: [Manrope](https://github.com/sharanda/manrope), [Geist](https://github.com/vercel/geist-font).

## Изменение анимации

Открой `public/rig/kuniman.glb` в Blender, измени ключи, экспортируй GLB с анимациями и замени этот файл. Название основного цикла — `Kuni_Idle`; если его нет, загрузчик использует первый цикл. Обнови `posed-preview.png`, когда существенно меняешь позу: это портрет для загрузки страницы и режима без WebGL.

Подробное руководство, Python-помощники для Blender и исходные изображения находятся в `animation/`. Лицо сохранено из утверждённого PNG без перерисовки. Это 2.5D-модель для небольших фронтальных движений; большие развороты требуют дополнительного рисунка скрытых участков.

## Разработка и публикация

Для установки нужен Node.js 24+ и pnpm 12.3.4. `Start.command` запускает уже собранный сайт на `http://127.0.0.1:3156`.

```sh
pnpm test
pnpm test:deploy
```

Первый запуск публикации с Mac — `bash Publish.command`. Сценарий переносит эту папку в `~/Project/kuniman`, предлагает вход в GitHub под `dmitryfun`, отправляет `main` в `dmitryfun/kuni`, затем подключается по SSH. Пароль сервера вводится в штатном скрытом запросе SSH и не хранится в проекте.

На сервере репозиторий размещается в `/root/Project/kuniman`. Приложение работает в отдельном production-контейнере без открытого наружу порта 3000. Существующий Caddy обслуживает HTTPS для `kuniman.me`. Инструкции обновления, проверки и отката: [deploy/README.md](deploy/README.md).

Проверка `/healthz` возвращает `{"status":"ok"}` без кэширования. Пользовательские API и база данных пока не нужны этой странице; Next.js сохранён для дальнейшего добавления проектов, музыки и интерактивности.

В GitHub Actions проверяются TypeScript, модель, сценарии деплоя и production build. Автоматический деплой с секретами GitHub не подключён.

Модель с увеличенной головой ранее проверялась в браузере. Последнее смещение головы влево проверено программно и на статичном портрете. Blender и производительность на телефоне пока не проверялись.
