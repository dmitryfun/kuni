# Kuni Man: риг и анимация

На сайте используется живой фотографический риг, а не видео. Файл `kuniman.glb` содержит модель, текстуры, 45 костей и цикл `Kuni_Idle` длительностью 12 секунд. Голова и глаза взяты из последнего утверждённого PNG без перерисовки. Голова увеличена на 15% относительно тела масштабом кости `head` и смещена немного влево для совмещения с шеей; нижний край волос сглажен. Тело и руки подготовлены под новую позу: одна кисть на груди, жест V у языка. Шарик — самостоятельный объект.

Движения небольшие: дыхание и покачивание корпуса, головы, плеч, предплечий, кистей, пальцев и языка. Размах растёт от плеча к кисти, фазы немного запаздывают. Все десять пальцев имеют отдельные цепочки; три согнутых пальца правой кисти рассчитаны на очень малое движение.

## Редактор и экспорт

Основной редактор — **Blender**, рекомендую ветку 4.5 LTS. Импорт и экспорт glTF/GLB входят в Blender; дополнительные расширения для этой модели не требуются. [Документация glTF](https://docs.blender.org/manual/en/4.5/addons/import_export/scene_gltf2.html).

1. Создай новый пустой проект. Через **File → Import → glTF 2.0** открой `kuniman.glb`.
2. Переключись в **Animation**, выбери скелет и **Pose Mode**. Включи предпросмотр материалов, чтобы видеть фотографию.
3. Выбери нужную кость и меняй её позу. Добавляй ключи через **Insert Keyframe** или автоключи. В Graph Editor можно менять амплитуду и плавность движения. Текущий цикл занимает кадры **0–360 при 30 fps**; ключи расположены примерно каждые 15 кадров. Первый и последний кадры совпадают.
4. Сохрани собственный `.blend`. Экспортируй через **File → Export → glTF 2.0**, формат **GLB**, с включёнными **Animations** и **Skinning**. Сохрани название цикла `Kuni_Idle`.
5. Замени `public/rig/kuniman.glb` в проекте сайта и пересобери сайт. Статичный запасной портрет находится рядом в `posed-preview.png`.

`animation/prepare_blender.py` — необязательный помощник: импортирует `public/rig/kuniman.glb`, настраивает камеру и шкалу времени, упаковывает изображения и сохраняет `animation/kuniman.blend`. Открой его в новом проекте через **Scripting → Open → Run Script**. Он не перезаписывает уже существующий `kuniman.blend`.

`export_glb.py` экспортирует изменённый сохранённый проект в `kuniman-export.glb`. Этот файл можно переименовать и перенести на сайт.

## Что проверено

Модель загружена настоящим Three.js GLTFLoader. Проверены геометрия, нормализация весов, индексы костей, конечность деформаций, совпадение начала и конца цикла, независимость головы и кисти. Встроенные PNG также декодированы. Утверждённая текстура лица встроена побайтно. TypeScript и производственная сборка Next.js проходят.

**Предыдущая версия с увеличенной головой проверена в браузере.** Последнее выравнивание пока проверено программно и на статичном портрете: локальный сервер выключен, его запуск из среды агента ограничен. Запуск Blender пока не выполнен: приложение отсутствует. Python-помощники проверены только на синтаксис; производительность на телефоне не измерялась.

## Возможности и границы

Это плоский фоториг с настоящими костями — 2.5D. Он рассчитан на спокойную фронтальную анимацию. Для разворота боком, полного разгибания согнутых пальцев и крупных новых поз потребуется подготовить скрытые участки изображения и проверить стыки. Одна фотография этих участков не содержит.

На публичной странице нет настроек рига. Есть маленькая пауза, поддержка `prefers-reduced-motion`, остановка скрытой вкладки и статичный портрет при недоступности WebGL. Реакции на курсор и перетаскивание пока не подключены.

`animation/authoring/` содержит исходные изображения, координаты, промпты и воспроизводимую сборку. Это технический исходник; для обычного изменения анимации достаточно Blender. PNG лица `animation/authoring/assets/approved-master.png` сохраняется без изменений.

Для сборки исходной модели из корня проекта:

```sh
npm install --prefix animation/authoring
node animation/authoring/build_rig.mjs
cp animation/kuniman.glb public/rig/kuniman.glb
cp animation/posed-preview.png public/rig/posed-preview.png
pnpm test
pnpm build
```

Промежуточные модели, previews и файлы Blender исключены из Git. Утверждённая экспортированная модель сайта лежит только в `public/rig/`.
